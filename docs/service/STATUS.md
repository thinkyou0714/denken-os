## 今回の変更

## 自動検証の範囲

`npm run verify`、`npm run test:coverage`、Sites配布物のビルドを公開前に実行する。画面操作はDOMで実行し、通常学習、ヒント、復習、模試、学習設定、ノート、教材検索、AI補助、計算・図・音声の補助、監修と運営を確認する。保存テストでは通信失敗、アカウント切替、同時編集、他端末の競合、破損データを扱う。

今回の実行結果は156ファイル・2,298テスト成功。`npm run verify` 成功。網羅率は文88.52%、分岐80.07%、関数91.85%、行92.51%で既存の基準をすべて満たした。サーバー側は実SQLiteのテストで検証し、網羅率の数値は既存設定の `lib`・`web/src` の計測対象に対する値である。

実ブラウザ・iPad・スマートフォンでの視覚確認、音声サービスの実通信、専門家による新教材監修、実利用者の学習効果測定は未実施。WebMCPは対応APIを模した契約・操作の検証であり、実ホストでの接続確認ではない。

## 残る準備

100案の内訳は、機能実装62件、機能実装・追加検証あり36件、条件付き機能・保留2件。詳細は [実装台帳](https://denken-os.thinkyou0714.chatgpt.site/service/implementation.html) と [JSON](implementation-plan.json) を参照する。

- 新しい教材・法規・二次採点観点は人の監修が必要。既存の確認済み52件を通常教材に使い、未監修の生成教材は検証用に分ける。
- 外部AI、画像認識、自動収集の稼働には、運営するサービスのキー・モデル・n8n接続設定が必要。管理画面の「設定済み」は実通信の成功を意味しない。
- 操作性・学習効果・難易度・継続価値の実測が必要。実測なしに合格確率や効果を保証しない。
- 未収録の年度・三種・CBTは、公式資料との照合と専用の試験プロファイルを追加してから提供する。
